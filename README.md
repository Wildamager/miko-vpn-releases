# Miko VPN

Miko — простой VPN-клиент для Android с подключением в одно нажатие. Приложение использует протокол VLESS + REALITY и получает персональную конфигурацию через защищённую активацию.

## Возможности

- быстрое подключение и отключение VPN;
- персональный профиль для каждого пользователя;
- активация по одноразовому коду из Telegram-бота;
- защищённая передача конфигурации: RSA-OAEP-256 и AES-256-GCM;
- отображение состояния подключения, времени сессии и трафика;
- работа в фоне с системным уведомлением Android;
- конфигурация VPN не хранится в APK.

## Установка

1. Скачайте файл `Miko-0.1.0-arm64.apk` из раздела Releases.
2. Разрешите установку приложений из выбранного источника, если Android запросит это разрешение.
3. Установите и откройте Miko.
4. В Telegram-боте откройте «Моя конфигурация» и нажмите «Код для приложения Miko».
5. Введите полученный код в приложении. Код действует 15 минут и предназначен для одной установки.
6. Нажмите кнопку подключения и подтвердите системный запрос на создание VPN-соединения.

## Системные требования

- Android 8.0 или новее;
- устройство с архитектурой ARM64 (`arm64-v8a`);
- доступ в интернет;
- активная подписка Miko VPN.

## Конфиденциальность и безопасность

Персональная VPN-конфигурация выдаётся сервером только после успешной активации и шифруется публичным ключом конкретного устройства. Закрытый ключ создаётся в Android Keystore и не покидает устройство.

Miko защищает трафик между устройством и VPN-сервером. Приложение не может гарантировать абсолютную анонимность и не заменяет осторожность при передаче личных данных сторонним сервисам.

## Поддержка

Если код не принимается, подключение не устанавливается или срок подписки отображается неверно, обратитесь в поддержку через Telegram-бота Miko.
